# 후보 원장 예산 메타데이터 재현

운영 파일 변경 없이 `/tmp`의 후보 원장에만 행과 메타데이터를 바꿨다. 현행 `tools/ledger-to-json.ts`와
`policy/ledger.rego`를 그대로 사용한 실제 로컬 결과다. 모델이나 외부 API는 호출하지 않았다.

| 입력 | 원장의 budget (MiB) | 행 limit 합계 (MiB) | conftest 종료 코드 |
|---|---:|---:|---:|
| baseline | 10240 | 9148 | 0 |
| over_budget | 10240 | 29148 | 1 |
| raised_candidate_budget | 50000 | 29148 | 0 |

기존 상한을 유지한 초과 후보는 실패하지만, 후보 메타데이터의 상한을 함께 높이면 통과한다.
이 결과는 plan r2 a1의 입력 신뢰 경계 지적을 뒷받침한다. 2026-09-12 사용자가 이 지적의 수용·설계 보완·추가 리뷰 1회를 선택했다. 이 표는 보완 전 반례다.
