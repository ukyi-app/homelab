# 기준 budget과 후보 rows의 입력 분리 대조

구현 전 계약을 확인하기 위해 `/tmp`에서 정책 입력을 수동 구성했다. 기존 파서와 OPA 정책은
수정하지 않았고, 기준 budget을 추출한 다음 후보 rows와 새 JSON으로 조합했다. 아래의 고정 기준
결과는 그 JSON에 대한 `conftest` 실제 종료 코드다. 운영 어댑터 구현·격리·게시 시험은 아니다.

| 후보 | 기준 상한 MiB | 후보 상한 MiB | 행 합계 MiB | 후보 기준 exit | 고정 기준 exit | 상한 변경 |
|---|---:|---:|---:|---:|---:|---|
| baseline | 10240 | 10240 | 9148 | 0 | 0 | False |
| raised_rows_and_budget | 10240 | 50000 | 29148 | 0 | 1 | True |
| raised_budget_only | 10240 | 50000 | 9148 | 0 | 0 | True |

초과 행과 상한을 함께 올린 후보는 후보 기준에서는 통과하지만 기존 기준에서는 실패한다.
상한만 올린 경우 기존 행의 통과와 상한 변경 사실을 분리할 수 있다. 기준/후보 메타데이터의
누락·중복·기형과 행 파싱 실패는 아직 구현할 어댑터의 수용 시험이며 이 실험으로 검증하지 않았다.
