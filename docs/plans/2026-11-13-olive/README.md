# 올리브 계획 (2026-11-13)

지금의 `homelab-bot`을 올리브로 전면 교체하는 계획이다. 올리브는 hc(herdr-core) 위에서 오래 사는 얇은 오케스트레이터와 일마다 띄우는 하위 에이전트로, 운영 중 문제가 생기면 스스로 원인을 찾아 PR을 올리고 병합은 관리자가 한다.

## 지금 상태

- 계획 초안. 2026-11-13에 관리자와 세부를 정했다(`spec.md` §5.1 D-01~D-35, 2026-11-14에 대화 방식과 진단 과정을 이어서 정했다). 구현 대기.
- 옛 봇은 꺼져 있다(O01: 게시 서버 homelab #1281, 작업자 둘 #1282). 만드는 동안 Discord 봇은 없고 경보는 Telegram으로 온다.
- 옛 봇의 멈춘 작업(C40~C47, 봇 PR #155)은 보류 중이다. 처리는 O07이 코드를 보고 정한다.
- 아직 안 정한 것은 `spec.md` §5.2(기본값, 관리자 미확정)와 §5.3(미정)에 있다. 검증 티켓(O02~O06)의 결과가 설계를 바꿀 수 있다.
