## 목표

O07이 "버림"으로 고른 옛 봇 코드·배포·경보가 저장소와 클러스터에서 사라진다. 옛 데이터 삭제는 명령을 적어 관리자가 실행한다.

## 할 일

1. 봇 저장소: "버림" 모듈과 그 시험을 지운다. 재사용 모듈의 import가 깨지지 않게 한다.
2. homelab: 옛 게시 서버·작업자 배포 중 올리브가 쓰지 않는 것, 옛 봇 경보 18개 규칙, 쓰지 않는 RBAC(`bot-reader` 등은 O11에서 대체됐다면)를 지운다.
3. 옛 데이터(DB 테이블, PVC, 백업 경로): 지울 대상과 명령을 적어 관리자에게 넘긴다. 에이전트가 직접 실행하지 않는다.
4. 옛 봇 계획(`docs/plans/2026-11-09-bot-colleague/`) README의 상태 줄에 "올리브로 대체됨"을 적는다.
5. 멈춘 작업(C40~C47, 봇 PR #155) 중 O07에서 "버림"이 된 것을 닫는 일은 관리자 승인 뒤에 한다.
