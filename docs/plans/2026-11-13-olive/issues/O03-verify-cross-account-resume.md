## 목표

한 계정의 Claude Code 세션을 끝낸 뒤, 다른 계정(구독 → 구독) 또는 다른 방식(구독 → API 키 `-p`)으로 같은 세션을 `--resume`할 수 있는지 확인한다. 안 되면 인계 문서로 새 세션을 여는 방식을 기본으로 정한다.

## 알려진 사실

- [확인] 실행 중 프로세스의 자격을 밖에서 바꾸는 공식 인터페이스는 없다. 전환은 "입력 정지 → 턴 확정 → 옛 프로세스 종료 확인 → 새 자격으로 resume"이다.
- [확인] `--resume`은 압축 전 전체 대화를 다시 싣지 않고, 중단된 도구를 다시 돌리지 않으며, 백그라운드 실행 상태를 복원하지 않는다.
- [확인] 세션 기록은 config 폴더 아래 프로젝트 경로별로 저장된다. 최신 문서는 절대 기록 경로로 `--resume`도 설명한다(설치본 help에는 없음).
- [미확인] 계정이나 인증 방식을 넘나든 `--resume`을 모델 쪽이 받아들이는지.

## 할 일

1. 올리브 전용 시험 config 폴더 두 개를 만든다. 관리자 개인 계정 폴더를 쓰지 않는다. 자격 값은 관리자가 넣는다.
2. 짧은 대화(모델 호출 몇 번)를 계정 A로 만들고 끝낸다. 종료를 확인한다.
3. 같은 기록을 계정 B(구독)로, 그리고 같은 계정 A의 API 키 `-p`로 각각 이어 연다. 기록 파일을 옮겨야 하면 어떤 파일(기록, 부속 폴더)이 필요한지 적고, 자격·계정 설정은 옮기지 않는다.
3-1. 실행 도구가 바뀌는 전환도 본다(D-15: 하위 에이전트는 크레딧 단계에서 OpenCode, 구독 단계에서 Claude Code). 도구가 다르면 기록을 이어 열 수 없다고 보고, 일 도중에 OpenCode(API 키) → Claude Code(구독)로, 다시 Claude Code → OpenCode로 넘길 때 인계 문서만으로 같은 일이 이어지는지 본다. 넘기기 전의 작업 상태·만든 파일·승인 영수증이 보존되는지, 같은 변경이 두 번 실행되지 않는지 적는다.
3-2. OpenCode 안에서 API 계정이 바뀌는 전환도 본다(크레딧 후보가 `claude-sub` 것 → `claude` 것으로 넘어갈 때). 새 전용 서버에서 인계 문서로 이어지는지 본다.
3-3. 끊긴 턴을 본다. 턴 도중에 끝낸 세션을 이어 열었을 때 끊긴 도구가 다시 돌지 않는지, `CLAUDE_CODE_RESUME_INTERRUPTED_TURN`을 막은 상태에서 확인한다. 헤드리스는 SIGINT로 끝낸 경우와 SIGTERM으로 끝낸 경우를 나눈다.
4. 각 경우의 성공 여부, 이어진 맥락의 범위(앞 대화를 기억하는지), 오류 모양을 적는다. "프로세스가 열렸다"와 "모델이 정상으로 답했다"를 따로 적는다.
5. 결과에 따라 `spec.md` §8.2 4번, `accounts.md` §5, O10·O17의 인계 방식을 고친다. 이어 열기가 안 되는 조합에는 인계 경로의 통과 결과가 있어야 한다. 감독은 여기서 통과한 인계 경로로만 새 세션을 스스로 연다(B-17).

## 완료 조건

- [ ] 구독 → 구독, 구독 → API 두 경우의 결과(됨/안 됨/조건부)와 근거가 있다.
- [ ] OpenCode → Claude Code, Claude Code → OpenCode 두 방향의 인계 결과가 있다. OpenCode의 API 계정 사이 결과도 있다.
- [ ] 통과로 적은 경우마다 목적·제약·부분 파일·입력 위치·승인과 게시 영수증·남은 예산이 이어졌고, 끊긴 부작용이 두 번 실행되지 않았다는 확인이 있다.
- [ ] 안 될 때 쓸 인계 문서의 최소 내용이 정해졌다(출발점은 `accounts.md` §5: 목적과 범위, 끝난 단계와 기다리는 단계, 만든 파일과 digest, 효과를 모르는 도구, 승인 영수증 위치, 남은 예산, 다음 한 단계).

## 검증

- 경계: 실제 모델 호출(최소 횟수). 관리자 개인 세션과 섞지 않는다.
- 잡는 실패: 다른 계정 기록 거부, 맥락 유실, 끊긴 턴의 재실행. 못 잡는 범위: 오래 쓴 세션(압축 뒤)의 resume, 세션 부속 파일과 background 자식이 있는 세션(할 수 있으면 한 번씩 보고, 못 보면 그 조합은 인계 문서를 쓴다).
