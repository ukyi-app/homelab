## 목표

`claude -p`와 OpenCode에 올리브용 Console API 키를 넣어 돌렸을 때 실제로 구독 포함 크레딧에서 차감되는지 Console 화면으로 확인한다.

## 알려진 사실

- [확인] 포함 API 크레딧은 대화형 Claude Code에는 쓸 수 없다. Console 키를 넣어도 제외 조건은 그대로다.
- [확인] 직접 실행하는 `claude -p`·Agent SDK에 연결 조직의 Console API 키를 넣으면 대상이다.
- [확인] 포함 크레딧은 연결 조직 공용이고, 다른 구매 잔액이 있으면 이어서 쓴다. 계정 폴더 수만큼 크레딧이 생기지 않는다.
- [미확인] OpenCode의 Anthropic 직접 API 사용이 포함분 대상인지, 실제 화면에서 포함분이 줄어드는지.

## 할 일

1. 관리자가 Console에서 확인한다: 구매 잔액·자동 충전 없음, 올리브 전용 workspace와 지출 한도, 구독 쪽 Usage credits 꺼짐. 값은 저장소에 적지 않는다.
2. 에이전트가 `claude -p`로 작은 실행 몇 번, OpenCode로 작은 실행 몇 번을 한다(올리브 전용 키, 관리자 개인 config 폴더 아님).
3. 관리자가 Console에서 포함 크레딧 잔액이 줄었는지, 다른 잔액이 쓰였는지 본다.
4. 결과를 "결과" 절에 적는다(됨/안 됨, 화면에서 본 항목 이름만).
5. 결과로 `spec.md` §8.3의 [미확인] 줄과 B-08(실행 도구 배정)을 고친다. OpenCode가 차감 대상이 아니면 B-08의 "막히면"대로 크레딧 작업자를 `claude -p`로 돌리는 안을 관리자에게 묻는다(D-14를 바꾸는 일이다).

## 완료 조건

- [ ] 두 계정 각각에 `claude -p`, OpenCode의 차감 결과가 있다.
- [ ] 크레딧을 쓴 뒤 그 계정의 구독 한도(5시간·주간 사용률)가 늘지 않았는지 적었다.
- [ ] "포함분 사용 중", "청구 0원" 같은 문구를 올리브 글에 쓰지 않는다는 규칙이 O17에 들어갔다.

## 검증

- 경계: 실제 과금 화면(사람). 에이전트는 Console에 접속하지 않는다.
- 잡는 실패: 포함분이 아닌 잔액 사용. 못 잡는 범위: 월 경계·정책 변경 뒤 동작.
