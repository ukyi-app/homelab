## 할 일

1. 켜기 전: O01이 끝났는지, 비상 정지가 CLI로 동작하는지, 상한(B-07)이 걸렸는지 확인한다. 켜기는 관리자 승인 뒤, `approvals.md`에 적는다.
2. AC-03~AC-20, AC-22~AC-27, AC-29~AC-32를 차례로 확인한다. 각 줄에 됨/안 됨과 근거를 적는다. AC-01과 AC-02의 앞 문장은 O01의 기록으로 닫혀 있는지만 본다(올리브를 켠 뒤의 상태로 다시 재지 않는다). AC-21은 O22가 닫는다.
3. 보안 확인(가짜 자격으로):
   - `/proc`·symlink·Unix 소켓·holder 소켓 접근 실패.
   - 훅 crash·timeout 때 거부.
   - 악성 PR 훅이 돌지 않음.
   - 승인 digest 변경·재전송 거부.
   - F-1~F-8 모든 출력 경로 차단.
   - 비상 정지 한 바퀴(D-38, D-39): 정지 → 확인 → 풀기. 정지 뒤 실행 파드 0개와 자물쇠, NUC에서 "정지 완료(노드 확인)", 재시작·재부팅 뒤에도 정지 유지, 정지 중 Argo CD 동기화에도 파드 0개.
   - `homelab olive watch`가 입력을 보내지 않고 없는 core를 띄우지 않음(D-37).
4. 부하: 실제 진단 하나와 PR 하나를 돌리는 동안 NUC load와 올리브 자원 사용을 기록한다. 다른 시험과 겹치지 않게 한다.
5. 하루 운영: 쉬는 시간 모델 호출 0번(AC-20), "오늘 배운 것" 한 번, 원문 정리 실행 기록.
6. 고칠 것은 해당 티켓으로 되돌리거나 새 티켓을 만든다.
