## 목표

API로 넘어감, 구독으로 돌아옴, API 잠김이 지워지지 않는 기록으로 남고, 지표와 브리핑이 그 기록과 맞는다.

## 할 일

1. 사건을 DB에 남긴다: 구독 한도 → API 선택, 첫 API 실행 확인, 구독 확인 성공 → 복귀, API 잠김. "선택됨"과 "실제 실행됨"을 나눈다.
2. 지표: 지금 방식, 넘어감·돌아옴 누계와 마지막 시각, API 잠김 상태와 이유 분류, API로 돈 실행 누계. 짧은 전환도 놓치지 않게 누계와 마지막 시각을 낸다. 값·지문·잔액은 내지 않는다.
3. 브리핑 한 줄(결정 5/6): "API 방식으로 이어서 한 실행 n회" 같은 관측 사실만. 잔액, 청구액, "포함분"이라는 말은 쓰지 않는다. 문구는 동료 말투와 스위치 켜짐 판 규칙을 따른다.
4. 관리 목록: 계정 아래 등록된 두 방식, 자동 사용 여부, 지금 방식, 구독 확인 예약, API 잠김 이유, API 실행 누계.
5. 실행 수 상한과 예약 장부는 만들지 않는다(결정 6/6). 누계는 보기용이고 `account use`나 복귀로 지워지지 않는다.
