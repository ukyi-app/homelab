## 할 일

1. 사람, 켜기 전(결정 2/6·6/6의 유일한 지출 안전장치): 구독에 연결된 Console 조직인지, 구매 잔액·자동 충전·후불이 없는지, 봇 전용 workspace와 지출 한도, 구독 쪽 Usage credits 꺼짐을 확인한다. 봇은 이 값을 볼 수 없다. 확인을 `approvals.md`에 적는다.
2. 사람: API 키 원본 등록, 자동 사용 `use`(plan 검토 뒤). 두 파드 반영을 확인한다.
3. 승인 뒤 스위치를 켠다. 되돌리는 법을 승인 요청에 같이 적는다.
4. 확인: 최소 API 실행 1회(실제 `apiKeySource`, 고정 모델, egress), 구독 한도 → API → 구독(허용된 상태 주입), API 잠김 뒤 구독만 복귀, 작업 세션의 구독 ↔ API 양방향 재개, Telegram 세 사건, 브리핑 한 줄.
5. 크레딧을 일부러 소진하거나 유료 결제를 내지 않는다. 실제 소진 표본이 없으면 "소진 오류 실측 미확인"으로 남긴다.
6. 양방향 재개가 실패하면 작업 경로의 자동 사용은 켜지 않은 채로 두고 근거를 반환한다.
7. 되돌리기 연습 1회와 Infisical 내보내기 갱신 안내.
