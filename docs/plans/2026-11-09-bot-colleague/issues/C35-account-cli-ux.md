## 목표

owner가 계정을 등록·전환할 때 묻는 것이 줄고(로그인 한 번, 프로젝트 ID 한 번), 토큰이 화면에 남지 않으며, 끝난 뒤에는 필요한 것만 몇 줄로 보인다. 자동화가 읽는 `--json`과 종료 코드는 그대로다.

## 결정 (사용자 2026-11-11)

- **로그인 한 번이 기본이다.** 토큰 하나를 대화용과 작업용에 함께 쓴다. 잃는 것은 한쪽만 교체·철회하는 것과 유출 때 토큰만으로 어느 쪽인지 가르는 것이다. 따로 받고 싶을 때의 선택지(예: `--per-lane`의 새 이름)를 둔다. 지금 `account add`의 "같은 토큰을 두 레인에" 거부를 이에 맞게 바꾼다.
- **"레인"을 사람에게 보이는 글에서 쉬운 말로 바꾼다.** 후보: "대화용"·"작업용"(작업자). 확정은 owner. 코드 식별자·Infisical 키 이름·Secret 이름은 바꾸지 않는다(운영 값과 CLI 판정이 묶여 있다).
- **`@clack/prompts`를 쓴다**(입력·확인·진행 표시). 터미널에서 사람이 쓸 때만이고, `--json`이거나 터미널이 아니면 지금 출력 그대로다.
- **끝난 뒤 출력은 요약이 기본이다.** 단계 표 전체와 실행한 `kubectl` 줄은 `--verbose`에서만 보인다. 실패하면 실패한 단계와 다음 행동은 늘 보인다.

## 할 일

1. `setup-token` 출력을 CLI가 직접 받아 토큰을 골라 저장한다(화면에 찍지 않고 붙여 넣기도 없다). 로컬 `claude setup-token`의 실제 출력 꼴(2.1.322에서 `sk-ant-oat01-…` 한 줄, 2026-11-11 관측)을 확인하고, 꼴이 다르면 지금처럼 가려진 입력으로 떨어진다. 브라우저 로그인 안내(URL)는 사람이 봐야 하므로 보이고 토큰 줄만 가린다. 값이 로그·오류 문구·`--json`에 섞이지 않는 시험을 둔다.
2. 로그인 한 번으로 두 자리(`CLAUDE_CODE_OAUTH_TOKEN`, `CLAUDE_CODE_OAUTH_TOKEN_TASK`)를 채운다. 따로 받는 선택지를 둔다. `account use`의 지문 확인은 두 값이 같아도 그대로 동작해야 한다.
3. 프로젝트 ID: 한 실행에서 한 번만 묻고, 묻지 않게 하는 방법(`HOMELAB_INFISICAL_PROJECT_ID`)을 물을 때 한 줄로 알려 준다. CLI가 값을 파일에 저장하지는 않는다(설계 C.7 "자체 상태 저장소 없음"). 이 결정을 바꾸려면(예: `~/.config` 파일) owner에게 묻는다.
4. `@clack/prompts`를 정확한 버전으로 더하고(`bun.lock`), 빌드에 묶는다. 명령 파일의 import 제한과 정적 시험을 깨지 않게 core의 입력·출력 계층에서만 쓴다. 가려진 입력이 지금처럼 에코 없이 받는지, 붙여 넣은 값이 화면 다시 그리기로 새지 않는지 시험·실측한다. 이 CLI는 토큰을 다루므로 의존성과 그 전이 의존성 목록·라이선스를 PR 설명에 적는다.
5. 결과 요약: 명령마다 "무엇이 바뀌었나, 지금 상태, 다음에 할 일"만 몇 줄. 예: `account use` → "지금 계정: main(구독) · 작업자 둘 반영 확인 · 멈춘 일 0건 해제". `account add`·`use`·`list`부터 하고, 다른 명령으로 넓힐지는 결과를 보고 owner가 정한다.
6. 사람에게 보이는 "레인"을 확정된 말로 바꾼다: CLI 출력·안내, `cli/README.md`, `rotate.md` 3e, 설계 C.7 줄. 봇 저장소의 문서·코드는 범위 밖이다(필요하면 따로 정한다).
7. 시험: 터미널이 아닐 때와 `--json`은 바이트 단위로 지금과 같다(기존 시험 유지), 요약에 값·토큰·프로젝트 ID가 없다, 로그인 한 번 흐름, 따로 받는 흐름, 토큰 꼴이 다를 때의 가려진 입력 대체.
8. 사람 단계: owner가 실제 터미널에서 `account add main --replace`와 `account use main`을 한 번 다시 해 보고 화면을 확인한다. 옛 토큰을 철회한다. 결과를 [approvals.md](../../2026-10-17-homelab-rebuild/approvals.md)에 적는다.
