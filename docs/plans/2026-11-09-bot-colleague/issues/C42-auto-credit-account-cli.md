## 목표

owner가 한 명령으로 한 계정의 구독 토큰과 API 키를 두 작업자에 함께 설치하고 자동 사용을 켜고 끌 수 있다. 수동 방식 하나만 쓰는 지금 명령은 그대로다.

## 할 일

1. `use`에 자동 사용 선택을 더한다(이름은 구현 때 정하고 근거를 적는다). 실제 방식 enum은 구독·API 둘 그대로다.
2. 자동 사용 `use`: 쓰기 전에 두 방식의 값 넷, 매핑, 작업자의 새 판 지원을 확인하고 하나라도 없으면 거부한다. 반대 방식 자리를 비우지 않는다. 계정 묶음(이름·revision·지문)을 설치하고 두 파드 반영을 확인한 뒤에만 봇 기록을 바꾼다.
3. 부분 실패 뒤 같은 명령을 다시 돌리면 같은 revision으로 이어 간다. 계정을 바꿀 때 옛 계정의 API 키와 새 계정의 구독 토큰이 섞이는 틈을 두지 않는다.
4. `list`: 등록된 두 방식, 자동 사용 여부, 지금 방식, API 잠김. 잔액은 보이지 않는다.
5. API 잠금 해제 명령(결정 3/6의 "owner가 직접 풀 때까지").
6. 값은 출력·로그·오류·argv에 나오지 않는다.
