# T11 데이터 서비스

- 단계: P2 플랫폼 구축 (잠정)
- 상태: 대기
- 명세: [../spec.md](../spec.md)
- Blocked by: T08, T09
- 선행 결정: D-05, D-06, D-22 (앱 DB 마이그레이션 방식)
- 연결 AC: AC-P9
- 수행: 에이전트

## 목표

앱에 PostgreSQL과 Valkey를 붙이는 흐름을 만들고, 데이터 수명을 앱 수명과 분리한다.

## 범위

- CNPG 설치와 공유 인스턴스 (D-05). DB·역할은 CNPG 선언형 기능으로 관리한다.
- R2 백업과 앱 단위 복원 절차.
- Valkey 캐시용·영속용 기본값 (D-06).
- 자격증명 원본은 Infisical, 사용 위치별 Secret은 자동 전달.
- 앱 삭제와 데이터 폐기의 분리.
- 데이터 저장 위치. 입력은 디스크 배치다: 루트 LV 913G, 별도 1.8T 디스크 `/mnt/bulk`. `/mnt/bulk`는 T06에서 비운 뒤 재사용할지 설계가 정한다(명세 §4.5).

## 완료 조건

시나리오 2, 3, 4, 8, 9, 10을 통과한다.

## 검증

- 테스트 앱에 DB와 캐시를 붙이고 접속을 확인한다.
- 비밀번호 회전 뒤 실제 앱 접속까지 확인한다.
- 앱을 지운 뒤 DB가 남아 있는지 확인한다.
- 공유 인스턴스에서 한 앱의 DB만 복원한다.
